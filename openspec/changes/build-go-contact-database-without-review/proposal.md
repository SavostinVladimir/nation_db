# Proposal

## Why

Нужна база контактов для надёжного хранения имён и телефонов и поиска в обе стороны. Вводные «хорошая» и «много записей» необходимо превратить в проверяемые требования к сохранности, удобству и вместимости.

## What Changes

- Создать с нуля на Go самостоятельное приложение с собственным файловым движком хранения, без SQLite и других готовых СУБД.
- Хранить записи «имя — телефон» с устойчивым идентификатором, проверкой данных и защитой от повторного добавления одинаковой пары.
- Предоставить точный поиск всех телефонов по имени и всех имён по нормализованному телефону с постраничными результатами.
- Предоставить HTTP JSON API и браузерный интерфейс для добавления и поиска контактов с одинаковыми правилами.
- Обеспечить сохранность подтверждённых записей после перезапуска и аварийного завершения, обнаружение повреждений и резервное копирование при остановленном сервере.
- Проверить работу на 1 000 000 записей с измеряемыми ограничениями ресурсов и задержек.

Границы первой версии (принятые допущения): один сервер на одном компьютере, локальный диск, один владелец данных; одна запись содержит одно имя и один телефон. Совпадающие имена и телефоны разрешены в разных парах. Изменение и удаление записей, нечёткий поиск, импорт, репликация, SQL, распределённые транзакции, аутентификация и публикация в интернете не входят в эту версию. Сервер по умолчанию доступен только через loopback. Это проект новой системы; исходного кода приложения в рабочем каталоге не обнаружено. Существующие спецификации намеренно не изучались по указанию пользователя.

## Capabilities

### New Capabilities

- `contact-records`: модель контакта, добавление, валидация и правила совпадений.
- `contact-lookup`: поиск имени по телефону и телефона по имени, порядок и пагинация.
- `durable-contact-storage`: собственное хранение на Go, восстановление, резервная копия и проверяемая вместимость.
- `contact-http-api`: программный HTTP JSON контракт добавления, получения и поиска.
- `contact-web-ui`: браузерные сценарии добавления и поиска, отображение результата и ошибок.

### Modified Capabilities

Нет. Изменение описывается независимо от существующих спецификаций в рамках эксперимента.

## Impact

Потребуются новый Go-модуль, файловый движок и его индексы, прикладной слой, HTTP-сервер, встроенные веб-ресурсы, тесты и документация запуска и восстановления. API и формат файлов будут новыми; миграций существующих данных в рамках этого изменения нет. Для первой версии достаточно стандартной библиотеки Go, HTML, CSS и JavaScript без отдельного сервера интерфейса и без внешней СУБД.
