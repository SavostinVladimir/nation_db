# Proposal

## Why

Нужна база имён и телефонов, позволяющая людям и программам находить связанные данные в обоих направлениях и сохранять их после сбоев. Подтверждённый масштаб первой версии — 100 миллионов записей; собственный движок хранения разрабатывается с нуля на Go.

## What Changes

- Добавить хранение записей «имя — телефон», создание и точный поиск по каждому полю, включая несколько совпадений.
- Создать собственный дисковый движок на Go с индексами, атомарной записью, восстановлением и ограниченным потреблением памяти.
- Предоставить веб-интерфейс и HTTP JSON API для одновременной работы нескольких пользователей с общей базой.
- Проверить сохранность при сбоях и работу на 100 миллионах записей; сделать расплывчатое «хорошая база» проверяемым через целостность, корректность поиска, понятные ошибки и измерение ресурсов.

Предлагаемые границы первой версии: один сервер, добавление и чтение записей, точное сопоставление после нормализации. Изменение и удаление, нечёткий поиск, SQL, распределённый кластер, репликация и отдельные пользовательские пространства не входят в этот change. Это проектные решения, а не дополнительные пожелания пользователя.

## Capabilities

### New Capabilities

- `contact-records`: модель записи, проверка данных и поиск в обоих направлениях.
- `durable-storage`: собственное надёжное дисковое хранилище, восстановление, параллельный доступ и объём 100 миллионов записей.
- `contact-http-api`: создание и поиск через общий HTTP JSON API с пагинацией и определёнными ошибками.
- `contact-web-ui`: добавление и поиск через браузер с понятными состояниями результата и ошибки.

### Modified Capabilities

Нет: `openspec list --specs` не обнаружил существующих спецификаций.

## Impact

Обзор файлов рабочего дерева на 2026-10-27 (`rg --files --hidden`, исключая `.git/`, `.idea/` и служебные каталоги навыков) выявил из исходников только `main.go` и `go.mod`: просмотрены стартовая программа и модуль `database`. В этом обзоре реализации базы, её интерфейсов и прежнего API для миграции не выявлено. Предлагаются новые Go-пакеты движка, предметной логики, HTTP-сервера, встроенных веб-ресурсов и проверок. Готовые СУБД и встроенные движки хранения не используются; стандартная библиотека и библиотеки общего назначения допустимы.

Режим развёртывания требует отдельного внимания: проект предлагает общую базу без разграничения прав в доверенной сети с ограниченным доступом. Публикация в интернете, аутентификация и управление ролями в этот change не включены; многопользовательский доступ здесь означает совместный конкурентный доступ к одним данным.
